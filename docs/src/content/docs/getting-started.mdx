SysopKit works with all Node-compatible runtimes. You'll need Node.js 22+ or Bun (`await using` requires explicit resource management support), plus an OpenSSH client for remote hosts.

## Quick Start

Create a file named `setup.ts` with the following content. It defines a two-host inventory and installs nginx on both machines:

```ts
import { apply, task } from 'sysopkit';
import { resolveInventory } from 'sysopkit/inventory';
import { start } from 'sysopkit/start';
import { sudo } from 'sysopkit/middleware/sudo';
import { createFile } from 'sysopkit/op/file';
import { sh } from 'sysopkit/op/sh';

const INVENTORY = {
  groups: {
    web: {
      hosts: {
        'web-1': { host: '192.168.1.10', user: 'sysop' },
        'web-2': { host: '192.168.1.11', user: 'sysop' },
      },
    },
  },
};

await start(async () => {
  await using hosts = resolveInventory(INVENTORY);

  await apply('setup nginx', hosts.getByGroup('web'), async () => {
    await sudo(async () => {
      await task('install nginx', async () => {
        await sh('apt install -y nginx');
      });

      await createFile({
        path: '/etc/nginx/sites-available/default',
        content: 'server { listen 80; }',
        mode: 0o644,
      });

      await task('enable nginx', async () => {
        await sh('systemctl enable --now nginx');
      });
    });
  });
});
```

Run the script with your preferred runtime:

<Tabs>
  <TabItem label="node" icon="node">
    <Code lang="sh" code="node setup.ts" />
  </TabItem>
  <TabItem label="Bun" icon="bun">
    <Code lang="sh" code="bun setup.ts" />
  </TabItem>
</Tabs>

:::note `setup.ts` is TypeScript, so Node must be able to strip types (Node 22.18+ runs it directly). On older Node versions, run with `node --experimental-strip-types setup.ts` or use a TS runner instead. :::
